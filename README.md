منصة هبوط احترافية عالية التحويل (High-Converting RTL Arabic Landing Page) مخصصة لأعمال **المهندس أحمد المحلاوي** (`@Ahmed_El_Mahalawy`)، المتخصص في صيانة وبرمجة شاشات عرض الليد إسكرين العملاقة (`Giant LED Video Walls P1 - P5`) بالميكروسكوب الإلكتروني، إصلاح البكسلات والآي سي، تركيب الشبك والماسكات، وإصلاح إضاءة المسارح وتجهيزات الصوتيات الاحترافية في المملكة العربية السعودية (جدة، مكة المكرمة، الطائف، الرياض، والمدينة المنورة).

## 🏗️ البنية الهندسية للمشروع (Modular Web Architecture)

تمت هندسة المشروع وتقسيمه بواسطة **المهندس نايف (Senior Web Architect)** لفصل المسؤوليات (Separation of Concerns) بين الهيكلة الدلالية (HTML5)، التنسيقات المخصصة (CSS3)، إعدادات التصميم (Tailwind Config)، البيانات المهيكلة (Data Store)، والمنطق التفاعلي (Vanilla JS Controller):

```text
f:\am\
├── index.html                  # الملف الرئيسي المهيكل (Semantic HTML5 + JSON-LD Schema.org SEO)
├── index.single.html           # نسخة احتياطية موحدة (Single-File Bundle) لمن يرغب بملف واحد مستقل
├── site.webmanifest            # ملف تعريف تطبيق الويب التقدمي (PWA Web App Manifest)
├── robots.txt                  # ملف توجيه محركات البحث (SEO Robots)
├── README.md                   # التوثيق الهندسي الشامل للمشروع
├── fahd_content_report.json    # قاعدة البيانات الخام المستخرجة من إعلانات حراج (63 صورة موثقة)
├── fahd_content_brief.md       # الملخص التنفيذي للمحتوى والصور
└── assets/
    ├── css/
    │   └── styles.css          # التنسيقات المخصصة (LED Matrix BG, Glassmorphism, Scrollbar, Animations, Print)
    └── js/
        ├── tailwind.config.js  # إعدادات نظام التصميم والألوان والخطوط (Tailwind CSS Configuration)
        ├── data.js             # مخزن البيانات المهيكل (window.MAHALLAWY_DATA) للمشاريع والمقاسات والتواصل
        └── main.js             # المحرك التفاعلي الرئيسي (معرض قبل/أثناء/بعد، الفلترة، الحجز عبر واتساب، Lightbox)
```

## ✨ المميزات الهندسية والتفاعلية

1. **فصل معماري نظيف (Clean Separation of Concerns):**
   - `index.html` نظيف تماماً من أي أكواد `<style>` أو `<script>` مطولة، مع دعم كامل لبيانات `Schema.org JSON-LD` (`LocalBusiness`, `ProfessionalService`, `Product`).
   - `assets/css/styles.css` يضم كافة التأثيرات البصرية المخصصة (خلفية مصفوفة الليد، البطاقات الزجاجية، الحلقات النابضة، وتنسيقات الطباعة).
   - `assets/js/tailwind.config.js` يضبط ألوان الهوية التقنية (`navy`, `tech.cyan`, `tech.emerald`, `tech.amber`) وخطوط `Cairo` و`Tajawal`.
   - `assets/js/data.js` يوفر كائن `window.MAHALLAWY_DATA` المركزي لسهولة تحديث أرقام التواصل أو المشاريع مستقبلاً.
   - `assets/js/main.js` يدير كافة التفاعلات بسلاسة تامة ويعمل مباشرة سواء عبر فتح الملف محلياً (`file://`) أو عبر خادم ويب (`http://` / `https://`) دون أي مشاكل CORS.

2. **الوظائف التفاعلية المدعومة 100%:**
   - **مبدل مراحل المشاريع (`switchProjectStage`):** استعراض تفاعلي فوري لمراحل الصيانة (1. قبل الصيانة • 2. أثناء الصيانة بالمعمل • 3. بعد الصيانة 100%).
   - **نظام تصفية المعرض (`Portfolio Filter`):** فلترة فورية للمشاريع حسب الفئة (الكل، المديولات والبكسلات والـ IC، إنقاذ الشاشات المتضررة، شاشات المسارح والبرمجة، الصوتيات والإضاءة).
   - **معرض مكسر ديناكورد الألماني (`setDynacordImage`):** تبديل تفاعلي بين 5 صور عالية الدقة لمكسر `DYNACORD PowerMate 1600`.
   - **اختيار مقاس البكسل المباشر (`selectPitchInForm`):** الضغط على أي مقاس من المقاسات الـ 20 (`P1` إلى `P5`) ينقل العميل لنموذج الحجز ويملأ المقاس تلقائياً.
   - **نموذج الحجز الذكي المرتبط بواتساب:** يجهز رسالة فنية منسقة بكافة بيانات العميل ويرسلها مباشرة إلى واتساب المهندس (`0545303140`).
   - **عارض الصور المكبر (`Lightbox Modal`):** تكبير أي صورة في الموقع بدقة كاملة مع دعم الإغلاق بزر `Escape` أو النقر خارج النافذة.

## 🚀 طريقة التشغيل

- **التشغيل المباشر:** افتح الملف `f:\am\index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Safari, Firefox).
- **التشغيل عبر خادم محلي (اختياري):**
  ```bash
  npx serve f:\am
  ```
